# 后端自动化测试

入口：`testing/run-backend-tests.ps1`。脚本会编译当前工作区代码，并在真实的 Minecraft 26.2 Fabric 专用服务端内执行测试，随后关闭并重新启动同一个测试存档，验证配置持久化。

## 运行

要求 PowerShell 7、JDK 25，以及与 Minecraft 26.2 匹配的 Carpet、Carpet Org Addition。`ModsDirectory` 只需各包含一个对应 JAR；脚本只复制这两个依赖，不复制其他模组。首次运行需要 Gradle 下载构建依赖；缓存齐全时加 `-Offline`。

在仓库根目录执行：

```powershell
./testing/run-backend-tests.ps1 `
  -JavaHome 'C:\Program Files\Microsoft\jdk-25.0.3.9-hotspot' `
  -ModsDirectory 'D:\MC\1.21.11\.minecraft\versions\26.2-Fabric 0.19.3\mods' `
  -EulaFile '你已接受协议的服务端目录\eula.txt' `
  -Offline
```

`EulaFile` 必须是已有且包含 `eula=true` 的文件。脚本复制该文件，不自动接受协议。

每次运行使用新的 `build/backend-tests/<时间-随机编号>/run/`。只监听 `127.0.0.1` 的随机端口，关闭 RCON；机器、方块、假人、规则默认值都只写入这个独立测试目录。不使用游戏原存档或正式服务端配置。测试结束正常停服，保留完整数据供排查；超时只终止本次脚本创建的进程树。默认每阶段超时 600 秒，可用 `-TimeoutSeconds` 调整。

结果保存在本次输出目录：

- `report.md`：逐项状态和失败堆栈。
- `report.json`：阶段结果、断言数量、依赖版本文件及 SHA-256。
- `junit.xml`：可供 CI 收集的 JUnit 格式报告。
- `suite.log`、`restart.log`：构建和服务端完整日志。
- `run/backend-suite.json`、`run/backend-restart.json`：实时阶段进度，`complete` 标识是否全部执行结束。

退出码 `0` 表示全量通过；`1` 表示断言失败、启动失败、超时或不完整；`2` 表示使用 `-SkipRestart` 跳过重启验证，只算部分运行。Gradle 的 `BUILD SUCCESSFUL` 不等于测试通过，应以脚本退出码和报告为准。失败用例会继续执行后续用例；缺失必测模块会触发覆盖守卫失败。

脚本会校验阶段名、完整标记、断言和用例计数。启动失败、非零进程退出、超时、不完整及损坏的阶段报告都会在 JUnit 中生成 `runner/phase-completion` 错误用例；超时前已经完成的用例仍保留。阶段报告采用原子替换，避免强制终止时留下半个 JSON；Windows 短暂读锁导致替换失败时最多重试 5 次，总退避等待 620 毫秒，每次重试写入日志，持续失败仍报错。基础套件未正常结束时不运行依赖它的重启阶段。

仅验证报告处理逻辑（无需 JDK、游戏依赖、EULA 或网络）：

```powershell
./testing/backend/test-runner-reports.ps1
```

该自检覆盖通过、断言失败、非零退出、超时、中途停止、缺失/损坏/字段不完整/计数不一致的 JSON、跳过重启、Unicode 和 XML 转义，并验证 JUnit 的计数与错误节点一致。

## 测试边界

这里的“全量”指上述后端功能模块的回归套件，**不是宣称所有代码行、所有分支或任意第三方扩展都达到 100% 覆盖**。

测试附属模组只装入脚本创建的目录，不进入正式发布 JAR，也没有修改产品代码。它使用真实服务器、Carpet 假人、世界方块、区块文件、原生指令及产品处理函数。仅对 `QAB_` 测试玩家替代网络发送/能力协商，用于记录服务端响应；因此它不验证真实客户端 socket、握手、UI 点击或渲染。七种数据包有独立编解码往返测试。

集成单人模式的作弊门控通过权限函数矩阵验证，不启动可视化单人客户端。未安装 Carpet 时的可选依赖降级、各种其他 Carpet 扩展版本、真实网络断线、磁盘写满和并发压测不包含在本套件中。现有 `tests/carpet-rules` 客户端联调工具可以补充实际客户端交互验证。

少量缓存过期、锁过期和管理器锁定用反射设置测试状态；被测判断仍执行产品实现。脚本不会为了消除失败而修改产品后端。

维护入口：`testing/backend/src/backendqa/BackendSuite.java`；测试网络观察器位于 `mixin/`。新增后端动作时应同时补充对应测试、覆盖表及必测模块列表。
