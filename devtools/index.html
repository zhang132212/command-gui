推荐工作流（第一次接入调优层后，后续无需再改源码）

  1. 界面微调：在浏览器里拖参数，右侧即时预览。
  2. 保存并部署：写入 config/command-gui/gui-tuning.json，游戏启动时自动生效。
  3. 文案翻译：修改后部署为 Command-GUI-DevTexts 资源包，不用重新构建 jar。
  4. 构建与部署：只有在第一次接入调优层、修改 Java 逻辑或分发 mod 时才需要构建；一键完成 build → 复制到 mods。
